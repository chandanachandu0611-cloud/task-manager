# Task Manager App

A simple and interactive **Task Manager** web application built using HTML, CSS, and JavaScript as part of the Web Development curriculum.

## 🔗 Live Demo
* **Live Application:** [View Task Manager on Vercel](https://task-manager-gamma-three-34.vercel.app)

## 🚀 Features
* **Dynamic Task Creation:** Add new tasks easily using input fields and DOM manipulation.
* **Task Status Management:** Mark tasks as completed or delete them as needed with responsive event listeners.
* **Input Validation:** Prevents empty tasks from being added to the list.
* **Clean & Modern UI:** Styled using modern CSS with intuitive layouts and user-friendly design.

## 🛠️ Technologies Used
* **HTML5** for structuring the application layout.
* **CSS3** for styling and modern presentation.
* **JavaScript (ES6)** for core logic, DOM manipulation, and event handling.

## 📁 Project Structure
* `index.html` - Main application interface structure.
* `style.css` - Styling rules and layout formatting.
* `script.js` - Application behavior, event listeners, and task management logic.
